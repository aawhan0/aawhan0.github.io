ch 01 · the spark

every build starts with
a what if?

Mostly it starts with someone complaining. A friend stuck on a workflow that almost works, a tool that breaks on real data, some "someone should really fix this" — and I'm already mentally rewriting it before they finish the sentence. Then I disappear for a weekend and come back with a repo nobody asked me for. This chapter is just an honest record of that.

ch 02 · the gap

fluent ≠ correct.

100%

grounded baseline · pass rate + root-cause accuracy

10%

Qwen 2.5 3B · 90% average confidence

The wrong answers are never the ones that sound unsure. I learned this the hard way — watched a model ace a demo, then fall apart the moment the inputs got messy. So now I ask the boring question first: against what ground truth? Thirty runs per config, three scenarios, every single time. It's unglamorous work and it's most of why I still ship.

ch 03 · the pipeline

promotion is earned.

register → version → gate → serve → watch

I don't like shipping things I can't defend, so ModelDock is built to be strict with me. Nothing gets promoted unless it clears the eval threshold — 72 tests in CI/CD, authenticated inference, drift monitoring once it's live. It's blocked my own releases more than once. Best feature in it, honestly.
